# Automated Storage and Retrieval System

Siemens TIA Portal V14 project for an automated storage and retrieval system.

## Download and open

1. Download [the complete TIA project ZIP](Auto_Storage_and_Retrieval_System.zip).
2. Extract the ZIP to a local folder.
3. Start Siemens TIA Portal V14 with the software components required by the project.
4. Choose **Open existing project**, browse to the extracted folder, and open `Auto_Storage_and_Retrieval System.ap14`.
5. Keep the extracted project folder and its subfolders together.

The ZIP contains a snapshot of the complete project directory, including its project database and supporting files. It is a standard folder ZIP. Extract it before opening the `.ap14` project in TIA Portal.

## Included files

- `Auto_Storage_and_Retrieval_System.zip` contains the TIA Portal project folder.
- `manifest.json` lists every packaged file with its size and SHA-256 checksum.

## Verification

The ZIP was checked for archive integrity, and each packaged file was compared against the original using SHA-256. Compilation, PLC execution, and an end-to-end simulation have not been verified as part of this upload.

## Simulation and demonstration

The separate simulation deliverable, Factory I/O scene, and demonstration video are planned additions. Any supporting simulation files already inside the original TIA project folder are retained in the project snapshot.
